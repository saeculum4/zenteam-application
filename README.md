# ZenTeam — Приложение для медитаций и осознанности

Мобильное и веб-приложение (PWA) для медитаций, созданное на базе Python (SQLite + HTTP-сервер без внешних зависимостей) и адаптивного фронтенда.

## Возможности
- **Экран приветствия и Главное меню** — спокойный минималистичный интерфейс с быстрым доступом ко всем 5 разделам.
- **Таймер медитации** — пресеты (5, 15, 30 мин + своё время), плавная абстрактная анимация дыхания на HTML5 Canvas, встроенный генератор спокойной музыки (тибетские чаши, эмбиент, лесной дождь, океанские волны) и статистика практик.
- **Анализ настроения и дневник** — шкала настроения, теги эмоций, текстовый дневник дня, блок благодарности, интерактивный SVG-график и история прошлых дней.
- **График медитаций** — интерактивный календарь, повторяющееся расписание, браузерные уведомления и звуковой будильник с быстрым переходом к медитации.
- **Места для медитаций** — интерактивная карта Москвы и Санкт-Петербурга с парками, садами и набережными, отзывами пользователей и возможностью добавить своё тихое место.
- **Сообщество** — живой чат по тематическим каналам, подборка статей и популярных блогеров по йоге и медитации, афиша событий, лидерборд и создание личного аккаунта.

## Запуск
```bash
py server.py
# или: python server.py
```
После запуска откройте в браузере `http://localhost:8080` (приложение также работает с телефона в той же Wi-Fi сети и поддерживает установку как PWA).
Или же открыть файл ZenTeam_Offline.html в любом браузере ( это оффлайн версия проекта, которая проще запускается - не требует установленного python и подключенного интернета)
